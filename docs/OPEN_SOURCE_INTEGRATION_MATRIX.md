# Open-Source Integration Matrix

Full comparison matrix across all 13 reference repositories, filled in from this audit's own
independent inspection (LICENSE files, package manifests, git history, docker-compose files —
see `OPEN_SOURCE_LICENSE_AUDIT.md` and `OPEN_SOURCE_DEPENDENCY_AUDIT.md` for the underlying
evidence) and cross-checked against `docs/FEATURE_STATUS.md` and
`docs/BROADER_WORKSTREAM_AUDIT.md` for what DevLaunch already has, so "Missing functionality"
reflects a real gap, not a feature that already exists under a different name.

**A note on "workstreams A-H"**: the master spec for this round describes 11 sibling agents
concurrently building 8 thematic workstreams (AI agent platform, workflow automation, growth
analytics/experiments, surveys, website intelligence, unified customer intelligence, sales
intelligence, social/communication intelligence) under `platform/`. No file in this repo
currently labels these A-H explicitly, so this document assigns the letters in the order the
task brief listed them, purely as a stable shorthand for the Decision column below — treat the
letter as a pointer to the theme, not a citation to an existing canonical document:

- **A** = AI agent platform
- **B** = Workflow automation
- **C** = Growth analytics / experiments
- **D** = Surveys
- **E** = Website intelligence
- **F** = Unified customer intelligence
- **G** = Sales intelligence
- **H** = Social / communication intelligence

## DevLaunch's existing baseline (from `FEATURE_STATUS.md`, read before filling this matrix)

Confirmed already built, not assumed: lead discovery/scoring/enrichment/ICP-matching pipeline;
deterministic (non-LLM) message drafting, content generation, chatbot, growth-analyzer, SEO
audit — every one of these explicitly documented in its own source as "not an LLM call, built
as a drop-in swap"; `agent_executions` as the existing RLS-scoped agent-orchestration system;
a BullMQ-based worker with 3 recurring jobs (agent-run worker, report schedule loop, sequence
scheduler cron); a native CRM (companies/contacts/notes/deals/meetings/activity-timeline); Postgres
row-level security as the sole multi-tenancy mechanism platform-wide; real (non-self-hosted)
integrations already built and wired for listmonk (email), chatwoot (live chat), and postiz-app
(social publishing) per Milestone 2; zero LLM credentials exist anywhere in the codebase today.

## Reading the Decision column against the current round

Of the 13 repos, 3 (chatwoot, listmonk, postiz-app) were already integrated in a **prior**
Milestone-2 round, before the current 11-agent round began — they are not being re-done now,
and this matrix's Decision entries for them reflect that completed state, not an in-flight
workstream. Of the remaining 10, 3 map onto workstreams genuinely being built in this round
(formbricks → Workstream D; posthog's Cloud-API pattern → Workstream C;
aaron-marketing-skills → Workstream A), and the remaining 7 (crawl4ai operational hygiene,
leadhub, mautic, n8n, OpenOutreach, twenty, mastra) are explicitly **not** being built this
round — see `OPEN_SOURCE_UPGRADE_BACKLOG.md` for the rejected/deferred ones and their reasons.
